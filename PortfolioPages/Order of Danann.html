Order of Danann (Unreal Engine 5, Gameplay Ability System)

Project information

  • Category: Unreal Engine 5, Gameplay Ability System
  • Motive: Create a versatile and engaging action RPG experience
  • Project date: 2024
  • Game Website: Order of Danann

Developed by Larkena Studio, Order of Danann leverages the powerful Gameplay Ability System (GAS) to deliver a rich and dynamic gameplay experience. As part of the development team, I contributed to several core systems that define the game’s mechanics and player interaction.

  1. Implemented the attack system, providing fluid and responsive combat mechanics.
  2. Developed a robust player interaction system to enable complex interactions within the game world.
  3. Created a versatile gameplay demo supporting both top-down and third-person perspectives to showcase multiple gameplay styles.
  4. Designed and implemented an intelligent enemy AI system to enhance player engagement and provide challenging encounters.

The project involved close collaboration across disciplines to ensure balanced gameplay and immersive experiences. Continuous iteration and playtesting helped refine each system to fit the vision of the game.
