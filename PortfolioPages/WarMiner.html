Developed in 2025, War Miner is a real-time strategy game that combines resource management, base building, AI-driven unit behaviors, and multiplayer gameplay. The project focused on creating a rich strategic experience for players through a variety of complex systems.

  1. Resource Collection System: Designed and implemented an efficient system for mining and managing resources vital for construction and upgrades.
  2. AI Unit Behaviors: Created intelligent behaviors for mining units and combat troops, including strategic movement, resource gathering, and engagement tactics.
  3. Base Construction Mechanics: Programmed mechanics to allow players to build, upgrade, and expand bases to gain strategic advantages on the battlefield.
  4. Combat System Development: Engineered a dynamic real-time combat system featuring unit health, damage calculations, and special abilities.
  5. Multiplayer Gameplay: Implemented real-time multiplayer functionality enabling both competitive and cooperative matches.
  6. User Interface Design: Developed an intuitive UI for resource management, unit control, and live game statistics display.

This project challenged me to integrate complex systems seamlessly within Unity using C#, emphasizing both gameplay depth and user experience. Despite lacking shareable visuals, the technical achievements represent significant contributions to RTS game design.
